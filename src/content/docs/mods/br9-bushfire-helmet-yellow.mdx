## What it changes

| | |
|---|---|
| Files | `pakchunk1003-BR9_Bushfire_Helmet_Yellow-Windows_P.pak` / `.utoc` / `.ucas` (chunk 1003) |
| Replaces | `S_FirefighterHelmet` (the helmet every firefighter wears) |
| Adds | Its own material and 2K textures. The visor uses the game's own glass |
| Detail | 12,000 triangles with 3 LODs (the switch isn't noticeable) |

Works on its own or with the other mods. The [QLD RFS Uniforms](/mods/qld-rfs-uniforms/) package already includes it.

[How to install](/mods/installing/). **Keep the file names exactly as they are.**
