Replaces the fire truck's European siren and horn with **Australian Hazard 1000 tones**. The game's volume sliders and distance fade still work as normal.

<LinkButton href="https://github.com/TonnieGit/rescueopsmodding/releases/latest/download/Hazard_1000_Tones.zip" icon="download">Download Hazard_1000_Tones.zip (114 KB)</LinkButton>

:::note
Already using the [QLD RFS Truck Reskin](/mods/qld-rfs-truck-reskin/)? It includes these tones, so you don't need this download. The files are identical.
:::

## What it changes

| | |
|---|---|
| Files | `z_Hazard_1000_Sounds_P.pak` / `.utoc` / `.ucas` (chunk 1001) |
| Replaces | `Audio/Vehicules/Siren/A_Firetruck_siren_loop_mono`, `Audio/Vehicules/Horn/A_Truck_Horn_Loop` |
| Keeps | The game's MetaSounds, so volume, SFX class and distance fall-off are unchanged |

In the truck: **K** toggles the siren, **H** sounds the horn. [How to install](/mods/installing/).
