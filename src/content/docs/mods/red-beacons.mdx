Turns every emergency light on the main fire truck (the CCF) **red** and makes them **much brighter**:

- **Roof beacons:** bright red rotators.
- **Grille and rear lightheads:** red, each flashing on **its own pattern**, with a soft glow that you see from the front.
- **Switched off:** the lenses are a muted red instead of blue.

The lights key (**J**) works as normal.

## What it changes

| | |
|---|---|
| Files | `pakchunk1004-Red_Beacons-Windows_P.*` (chunk 1004) |
| Replaces | `S_CCF_FlashingLight_01`, `S_CCF_FlashingLightRotatingMesh_01`, `S_CCF_BeaconLightx2_01`, `S_CCF_BeaconLightx4_01` |
| Adds | Materials `M_TonnieBeacon`, `M_TonnieBeaconGlow` and three instances |

Works on its own or with the [QLD RFS Truck Reskin](/mods/qld-rfs-truck-reskin/), which already includes it.

## Known limitations

- The beacons **glow but don't light up** the ground or walls around the truck. The game gives them no real light sources.
- The four roof beacons **spin in step**. The game spins them all at the same speed.
