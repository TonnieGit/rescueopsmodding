## What it changes

| | |
|---|---|
| Uniform | `z_FirefighterTex_P.pak` / `.utoc` / `.ucas` (chunk 1000): `T_FirefighterBody_D`, `_N`, `_RM` at 4096² |
| Helmet | `pakchunk1003-BR9_Bushfire_Helmet_Yellow-Windows_P.*` (chunk 1003), the same files as the standalone [helmet mod](/mods/br9-bushfire-helmet-yellow/) |

Without the helmet files, the game's original helmet comes back, painted white by the uniform texture (as in v1).

[How to install](/mods/installing/). Set **Texture Quality to Epic** for sharp logos.
