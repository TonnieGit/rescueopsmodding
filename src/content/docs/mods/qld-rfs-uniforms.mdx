## What it changes

| | |
|---|---|
| Files | `z_FirefighterTex_P.pak` / `.utoc` / `.ucas` (chunk 1000) |
| Replaces | `T_FirefighterBody_D`, `_N`, `_RM` at 4096² |
| Affects | The firefighter suit **and** helmet (they share one texture set) |

[How to install](/mods/installing/). Set **Texture Quality to Epic** for sharp logos.
