All mods are for the **Steam demo** (version 0.8.4, Unreal Engine 5.8.1, October 2026). They only add files and never change the game's own, so they can be installed and removed independently. New here? The easiest way to install them is the [Mod Launcher](/mods/installing/).

Brighter, Red and Red + Blue Beacons, the Free Camera and ELS share two small parts, [Tonnie Core and Beacon Base](/mods/tonnie-core/). The [Mod Launcher](/mods/installing/) installs them for you. The ELS Light Bar replaces the front roof beacons, so use it or a beacon colour, not both.

## Compatibility

| | Uniforms | BR9 Helmet | Truck Reskin | Beacon colours (Brighter / Red / Red + Blue) | Free Camera | Hazard 1000 Tones |
|---|---|---|---|---|---|---|
| Files added | `z_FirefighterTex_P.*` + `pakchunk1003-BR9_Bushfire_Helmet_Yellow-Windows_P.*` | `pakchunk1003-BR9_Bushfire_Helmet_Yellow-Windows_P.*` | `z_QLD_Truck_P.*` + `z_Hazard_1000_Sounds_P.*` + Red + Blue Beacons | `pakchunk1009-Brighter_Beacons` / `pakchunk1008-Red_Beacons` / `pakchunk1007-Red_Blue_Beacons-Windows_P.*` + Beacon Base + Tonnie Core | `pakchunk1006-Free_Camera-Windows_P.*` + Tonnie Core | `z_Hazard_1000_Sounds_P.*` |
| Works with the others | ✅ | ✅ (the Uniforms already include it) | ✅ (comes with Red + Blue; installing another colour swaps it) | ✅ one colour at a time | ✅ with everything | ✅ (the Truck Reskin already includes it) |
