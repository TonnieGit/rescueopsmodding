:::note[You don't need Unreal Engine to play mods]
Unreal, FModel and the other tools are only for **making** mods. To play them, you only need the game and the mod's download.
:::

Every mod here is a set of **three files** (`.pak`, `.utoc`, `.ucas`) that you add to the game. No game files are changed. There are three ways to install them. All give the same result.

## Option 1: Mod Launcher (easiest)

The Rescue Ops Mod Launcher is a small app that downloads, updates and loads every mod on this site, then starts the game. It always shows the latest versions, so you never need to come back here to check for updates. It replaces the old Mod Manager.

<LinkButton href="https://github.com/TonnieGit/rescueopsmodding/releases/latest/download/RescueOpsModLauncher.exe" icon="download">Download RescueOpsModLauncher.exe (1.1 MB)</LinkButton>

<Steps>

1. Double-click the downloaded **`RescueOpsModLauncher.exe`**. There's nothing to install: it's a single file you can keep anywhere, for example on your desktop.

2. If Windows shows **"Windows protected your PC"**, click **More info** → **Run anyway**. It warns about every app downloaded from the internet that isn't signed.

3. Pick **English** or **Français**. You can change it later in **Options**.

4. The launcher finds the game through Steam. Click **Mods** → **All mods**:

   <Image src={launcher} alt="The Rescue Ops Mod Launcher on the All mods tab: mods grouped under Lights and sirens, Uniforms and gear, Vehicles and liveries and Tools, each with a checkbox, thumbnail, author, version, status and size. Red + Blue Beacons is selected and its details are on the right, with a Download and load button." />

5. Tick a mod to load it. If it isn't downloaded yet, the launcher downloads it, checks every file, and loads it along with anything it needs.

6. Click **Play**. The game starts through Steam with the ticked mods.

</Steps>

Untick a mod to stop it loading. Its files move to a library folder next to the game (`Wildfire\ModLibrary`), so ticking it again is instant. To delete a mod from your PC, click it and click **Delete**.

- **Loaded** lists what loads with the game. **All mods** lists everything, with a search box and category, author and sort filters. **Updates** lists mods with a newer version: click **Update all**.
- **Dashboard** shows news from the game's developers (patch notes) and from this hub, and alerts such as updates or a game update.
- **Add mod files** adds a mod from somewhere else (its `.pak`, `.utoc` and `.ucas`, or a zip). It's listed under **Added by you** and loads like any other mod.

What the launcher does:

- It finds the game in every Steam library on the PC. If it can't, go to **Options** → **Game** → **Change** and pick the game folder (see [Install by hand](#option-3-install-by-hand), step 2, for how to find it).
- It checks every downloaded file against the list of mods before using it. If anything doesn't match, nothing is changed.
- It only moves the mod files. It never changes or deletes the game's own files.
- If you tick two mods that change the same thing (for example [Beacons: Red](/mods/red-beacons/) and [Beacons: Red & Blue](/mods/red-blue-beacons/)), it asks which one to keep.
- Some mods need a shared part ([ROMF and Beacons: Light Engine](/mods/tonnie-core/)). It loads those for you and asks before unloading a mod that something else needs.
- It locks the mod list while the game is running and unlocks it when you close the game.
- It updates itself. When a new version is out, it asks, downloads it, checks it and restarts.

Mods you installed with the old Mod Manager or by hand stay as they are: the launcher shows them as loaded.

Its source code is [on GitHub](https://github.com/TonnieGit/rescueopsmodding/tree/main/manager) if you'd like to read exactly what it does.

:::caution[Gotcha: "Couldn't reach the modding hub"]
**Cause:** the launcher reads the list of mods from GitHub, so it needs an internet connection.

**Fix:** check your connection and click **Retry** on the dashboard. Mods you've already downloaded still load and play without internet.
:::

:::caution[Gotcha: the launcher flickers or draws black]
**Cause:** some graphics drivers don't get on with the launcher's glass effects.

**Fix:** go to **Options** → **Launcher** and untick **Glass effects and graphics acceleration**, then restart the launcher.
:::

:::note[Still on the Mod Manager?]
It keeps working, and shows a link to download the launcher. You can delete `RescueOpsModManager.exe` once you have the launcher.
:::

## Option 2: Install.bat

Every mod download also comes with an `Install.bat` that finds the game and copies that mod's files in for you.

<Steps>

1. Close the game.

2. Right-click the downloaded zip → **Extract All** → **Extract**.

3. Open the extracted folder and double-click **`Install.bat`**.

4. If Windows shows **"Windows protected your PC"**, click **More info** → **Run anyway**. It warns about every script downloaded from the internet that isn't signed.

5. A window opens and installs the mod:

   ```text
    Installing into:
      C:\Program Files (x86)\Steam\steamapps\common\Rescue Ops Demo\Wildfire\Content\Paks

      Added   pakchunk1004-Red_Beacons-Windows_P.pak
      Added   pakchunk1004-Red_Beacons-Windows_P.utoc
      Added   pakchunk1004-Red_Beacons-Windows_P.ucas

    Done. Start the game to use Red Beacons v1.
   ```

   Press any key to close it, then start the game.

</Steps>

What `Install.bat` does:

- It finds the game in every Steam library on the PC, including other drives. If it can't, it asks you to drag the game folder onto its window (see [Install by hand](#option-3-install-by-hand), step 2, for how to find it).
- It waits for you to close the game if it's still running.
- It only **adds** the mod's files to `Wildfire\Content\Paks`. It never changes or deletes the game's own files.
- If you have a mod that changes the same thing (for example [Beacons: Red](/mods/red-beacons/) and [Beacons: Red & Blue](/mods/red-blue-beacons/)), it asks before removing the old one. Answer **N** and nothing is changed.

It's a plain text file. Right-click it → **Edit** (or open it in Notepad) to read exactly what it does before you run it.

:::caution[Gotcha: "Can't find the mod files next to this installer"]
**Cause:** you ran `Install.bat` from inside the zip. Windows only unpacks the `.bat` itself, not the mod's files.

**Fix:** close the window, right-click the zip → **Extract All**, and run `Install.bat` from the extracted folder.
:::

:::caution[Gotcha: "Windows blocked the install"]
**Cause:** the game was still open, or your Steam library is in a folder your Windows account can't write to.

**Fix:** close the game. If it still fails, right-click `Install.bat` → **Run as administrator**.
:::

## Option 3: Install by hand

<Steps>

1. Close the game.

2. Open the game folder: **Steam → Library → right-click the Rescue Ops: Wildfire demo → Manage → Browse local files**. It contains `WildfireDemo.exe` and a folder called `Wildfire`. It's usually:

   ```text
   C:\Program Files (x86)\Steam\steamapps\common\Rescue Ops Demo
   ```

   It can be on another drive, so use "Browse local files" to be sure.

3. Go into **`Wildfire\Content\Paks`**. You should see `Wildfire-Windows.pak`, `.ucas` and `.utoc`.

4. Copy the mod's files into that `Paks` folder. Keep the names exactly as they are.

   **Shortcut:** each download has a `Wildfire` folder inside. Copy it into the game folder from step 2 and let Windows merge it. If Windows asks to replace a file that **isn't** one of the mod's own, click Cancel and copy the files by hand.

5. Start the game.

</Steps>

Installing [Beacons: Red](/mods/red-beacons/) or [Beacons: Red & Blue](/mods/red-blue-beacons/) by hand? Delete the other one's three files first. They change the same lights.

:::tip[Set Texture Quality to Epic]
On Medium the game shows textures at a quarter of their size, so logos and lettering look blurry. In the graphics settings, set **Texture Quality** as high as it goes.
:::

## Uninstall

In the Mod Launcher, untick the mod to stop it loading, or click it and click **Delete** to remove it from your PC.

By hand, delete the mod's three files from `Wildfire\Content\Paks`. `Install.bat` lists them, and so does each mod's `INSTALL.txt`.

Steam's **Verify integrity of game files** will **not** remove them. It only repairs changed or missing files, and mod files are extra files.

## Check the files (optional)

Each mod's `INSTALL.txt` lists SHA-256 hashes. In PowerShell:

```powershell
Get-FileHash .\z_FirefighterTex_P.* -Algorithm SHA256
```

## After a game update

The mods were built for the demo on Unreal Engine 5.8.1. If an update makes a mod look or sound wrong, or stop working, delete its files. It may need rebuilding.
