Two small shared parts sit under the beacon mods and the Free Camera. You don't need to install them yourself: the [Mod Manager](/mods/installing/#option-1-mod-manager-easiest) adds them when a mod needs them, and every zip that needs them includes them.

| Part | Used by | What it does |
|---|---|---|
| **Tonnie Core** | [Brighter](/mods/brighter-beacons/), [Red](/mods/red-beacons/) and [Red + Blue Beacons](/mods/red-blue-beacons/), [Free Camera](/mods/free-camera/), [QLD RFS Truck Reskin](/mods/qld-rfs-truck-reskin/) | When a fire truck appears, starts whichever of those mods you have installed. If a mod isn't installed, it's simply skipped |
| **Beacon Base** | The three beacon colours and the Truck Reskin | The beacon materials and meshes, and a real light for each of the truck's 10 beacons. The colour comes from the beacon mod you install |

## How it works

Tonnie Core replaces one small game Blueprint, the truck's storage-box linker, with an identical copy whose storage logic matches the game's original one-to-one. The copy also starts the mods. It finds each mod by name, so a mod that isn't installed can't cause a crash.

## After a game update

The Core copies a game file, so a game update that changes that file can break it. If the game crashes while loading after an update:

1. Remove the three `pakchunk1005-Tonnie_Core-Windows_P` files from `Wildfire\Content\Paks` (or untick **Tonnie Core** in the Mod Manager and uninstall it; it offers to remove what needs it).
2. Your other mods (uniforms, helmet, truck paint, Hazard 1000 tones) keep working.
3. Check back here, or the Mod Manager, for an updated Core.
