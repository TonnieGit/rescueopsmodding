Two small shared parts sit under the beacon mods, the Free Camera, Camera: First Person, ELS and Lights: HQ. You don't need to install them yourself: the [Mod Launcher](/mods/installing/) adds them when a mod needs them, and every zip that needs them includes them.

| Part | Used by | What it does |
|---|---|---|
| **ROMF: Rescue Ops Mod Framework** | [Beacons: Blue](/mods/brighter-beacons/), [Red](/mods/red-beacons/) and [Red & Blue](/mods/red-blue-beacons/), [Free Camera](/mods/free-camera/), [Camera: First Person](/mods/first-person/), [QLD RFS: Fire Truck](/mods/qld-rfs-truck-reskin/), [ELS: Sirens](/mods/els/), [ELS: Light Bar AUS](/mods/els-light-bar/), [ELS: Light Bar France](/mods/els-france/), [Lights: HQ Real Light](/mods/lights-hq/) | When a fire truck appears, starts whichever of those mods you have installed. If a mod isn't installed, it's simply skipped |
| **Beacons: Light Engine** | The three beacon colours, the QLD RFS: Fire Truck and ELS: Light Bar France | The beacon materials and meshes, and a real light for each of the truck's 10 beacons. The colour comes from the beacon mod you install. Runs in Lite mode unless [Lights: HQ](/mods/lights-hq/) is installed |

ROMF was called Tonnie Core, and Beacons: Light Engine was called Beacon Base. The file names haven't changed.

**ROMF v3** starts [Camera: First Person](/mods/first-person/), which needs v3. **ROMF v2** started [ELS: Sirens](/mods/els/). The other mods work with any version from v2 on.

**New in Light Engine v2:** Lite by default. The real light no longer casts shadows and follows a real LED beam shape, so it costs almost no FPS. Add [Lights: HQ Real Light](/mods/lights-hq/) for the full-quality look.

## How it works

ROMF replaces one small game Blueprint, the truck's storage-box linker, with an identical copy whose storage logic matches the game's original one-to-one. The copy also starts the mods. It finds each mod by name, so a mod that isn't installed can't cause a crash.

## After a game update

ROMF copies a game file, so a game update that changes that file can break it. If the game crashes while loading after an update:

1. Remove the three `pakchunk1005-Tonnie_Core-Windows_P` files from `Wildfire\Content\Paks` (or untick the mods that use it in the Mod Launcher).
2. Your other mods (uniforms, helmet, truck paint, Hazard 1000 tones) keep working.
3. Check back here, or the Mod Launcher, for an updated ROMF.
