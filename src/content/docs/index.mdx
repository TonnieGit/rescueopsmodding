## What works today

<CardGrid stagger>
	<Card title="Texture replacement" icon="seti:image">
		Replace any cooked texture by rebuilding it at the same path in a blank `Wildfire` project. Proven on the firefighter uniform, helmet and CCF fire truck.
	</Card>
	<Card title="Sound replacement" icon="seti:audio">
		Swap SoundWaves (sirens, horns) and keep the game's own MetaSounds, so volume sliders and distance fall-off still work.
	</Card>
	<Card title="No game files touched" icon="approve-check">
		Mods are extra `z_*_P` pak containers. Uninstall by deleting three files. The game isn't encrypted or signed and has no anti-cheat.
	</Card>
	<Card title="Stock tools only" icon="setting">
		FModel, a `.usmap` mapping file and Unreal Engine 5.8 from the Epic launcher. No custom toolchain needed.
	</Card>
</CardGrid>
