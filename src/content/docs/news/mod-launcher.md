The [Rescue Ops Mod Launcher](/mods/installing/) replaces the Mod Manager. It's still one small file with nothing to install.

- **Tick to load, untick to stop.** Unticked mods are kept next to the game, so switching between them is instant.
- **Play** starts the game through Steam with the ticked mods. The mod list locks while the game runs.
- **Dashboard** with the developers' patch notes, news from this hub, and alerts when a mod or the game updates.
- **All mods** with thumbnails, categories, search and filters. **Updates** updates everything in one click.
- **Add mod files** loads mods from elsewhere alongside the hub mods.
- **English and French**, picked the first time you open it.
- It updates itself.

Mods you installed with the Mod Manager are picked up as they are. The Mod Manager keeps working and links to the launcher.
